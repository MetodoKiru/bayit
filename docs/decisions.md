# Decisiones iniciales

- Bayit es una aplicación independiente de Método Kiru.
- Interfaz en español, diseño cálido y minimalista: crema, arena, marrón y oliva.
- La primera versión prioriza identidad, hogares, miembros y permisos de compartición.
- Calendario nativo: no depender de Google Calendar para el MVP.
- Una persona conserva un único perfil aunque pertenezca a varios hogares.
- La conexión entre hogares no comparte datos automáticamente.
- Las tareas domésticas son privadas de cada hogar.
- No se aplicarán migraciones hasta revisar el esquema y las políticas RLS.
