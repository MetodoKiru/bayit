# Fase 7 — cambios de última hora y datos incompletos

## Principio: el formulario mensual no es una barrera
El formulario del día 25 es una revisión guiada, no la única forma de introducir disponibilidad. Cualquier miembro puede:
- Añadir un evento o bloqueo en cualquier momento.
- Editar hora, fecha, duración, prioridad y visibilidad.
- Cancelar un compromiso sin borrar el historial.
- Marcar un evento como provisional o confirmado.
- Informar de un cambio de última hora.
- Duplicar un evento recurrente y modificar solo una ocurrencia.

## Flujo de captura
- Acción persistente «+ Añadir plan» en calendario y dashboard.
- Formulario rápido con título, fecha, franja, categoría y prioridad.
- No exigir todos los campos para guardar; permitir completar más tarde.
- Guardar como provisional y recordar completar datos opcionales.
- Conflictos posteriores recalculan disponibilidad y avisan al propietario.
- Si un evento cambia, recalcular propuestas abiertas; no confirmar/reprogramar automáticamente.
- Si no se ha respondido al formulario mensual, mostrar disponibilidad «sin actualizar», nunca libre.
- En planificador compartido, mostrar hora de última actualización de disponibilidad y pedir confirmación antes de cerrar fecha.

## Revisión inteligente mensual
- Comparar respuestas con eventos existentes.
- Mostrar diferencias: nuevo, modificado, sin confirmar, posible duplicado.
- No crear un segundo evento si ya existe uno equivalente.
- Solicitar confirmación para modificar o borrar eventos preexistentes.
- Permitir responder «este mes no tengo cambios».
